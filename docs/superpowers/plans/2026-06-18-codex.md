# Codex (энциклопедия контента) — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Вкладка «Кодекс» в хабе кампании — справочник по предметам, умениям, модификаторам и врагам из TS-каталогов; прогрессивное открытие записей в `CampaignState`; переключатель «Показать всё» (default `true`).

**Architecture:** Единый реестр `src/game/codex/registry.ts` + чистый слой открытий `discovery.ts`; тексты через существующие `itemText`/`cardText` и новые `enemyText`/`modText`; хуки открытия в `runReducer` (покупка, merge после боя) без React в ядре; UI — `CampaignCodexTab` + подкомпоненты в `src/features/codex/`.

**Tech Stack:** TypeScript strict (`tsconfig.app.json`), Vitest (`npm run test`), React 19 + Ant Design 6, Zustand 5, Vite 8.

**Spec:** `docs/superpowers/specs/2026-06-18-codex-design.md`

## Global Constraints

- Формат id записи: `{category}:{templateId}` (`item:`, `card:`, `enemy:`, `mod:`).
- Неоткрытые записи **не показываются** в игровом режиме; счётчик «Открыто N / M» по категории.
- Открытия в `CampaignState.codexDiscovered`; просмотренные — `codexSeenEntryIds`; тот же `localStorage`.
- Триггеры: предмет — купил/получил; умение — использовал в бою; враг — убил; мод — `level` слота впервые > 0.
- «Показать всё»: локальный `useState`, default **`true`**, `// TODO(release): CODEX_SHOW_ALL_DEFAULT = false`.
- Кодекс только в хабе; вкладка **disabled** при `inBattle`.
- `SAVE_VERSION` **2**; миграция v1→v2 добавляет пустые codex-поля.
- Не использовать Ant Design `Tabs` для подменю категорий — кнопки как в `CampaignHubNav`.

export function applyModKillReward(card: CardInstance, points: number): CardInstance {

  const modifications = card.modifications.map((m, i) =>
