# Дизайн: верхнее меню хаба кампании (Персонаж · Бой · Магазин)

**Дата:** 2026-06-18  
**Статус:** согласовано в brainstorming  
**Связь:** `src/features/campaign/CampaignHub.tsx`, `src/features/profile/HeroProfileModal.tsx`

## 1. Цель

Переделать одностраничный хаб кампании в **игровую навигацию**: постоянный HUD статов и три вкладки в верхнем меню — **Персонаж** (слева), **Бой** (по центру), **Магазин** (справа). Соответствующие блоки переносятся на вкладки без изменения игровой логики (store, reducers).

## 2. Макет

```
┌─────────────────────────────────────────────┐
│  Gen — кампания          (заголовок Card)   │
├─────────────────────────────────────────────┤
│  ⭐12   🪙 150   ⚡ worldPower: 3            │  ← HUD, всегда
├─────────────────────────────────────────────┤
│     [ Персонаж ]  [ Бой ]  [ Магазин ]      │  ← nav, по центру
├─────────────────────────────────────────────┤
│           контент активной вкладки          │
└─────────────────────────────────────────────┘
```

### 2.1. HUD (все вкладки)

- Одна строка под заголовком Card, над меню.
- Содержимое: `⭐{playerUnitLevel}` · `🪙 {gold}` · `⚡ worldPower: {worldPower}`.
- На узкой ширине — перенос (`Space wrap`), без горизонтального скролла.
- Эмодзи и стиль согласованы с текущим хабом; где уместно — константы из `src/game/ui/labels.ts`.

### 2.2. Навигация

- Три кнопки в одном ряду, **выровнены по центру**.
- Порядок: **Персонаж** · **Бой** · **Магазин**.
- **Активная вкладка** — `type="primary"`, неактивные — `type="default"`.
- Центральная «Бой» выделяется **позицией** (и при желании иконкой `PlayCircleOutlined`), не постоянным primary при выборе других вкладок.
- Реализация: локальный `activeTab` + условный рендер одной панели; **не** использовать Ant Design `Tabs` (кастомная «игровая» вёрстка).

### 2.3. Вкладка «Бой» (по умолчанию)

- При открытии хаба и после возврата из боя — активна вкладка **«Бой»** (без сохранения вкладки в store).
- Содержимое (из текущего `CampaignHub`):
  - если кампания не завершена: кнопка «Начать / продолжить бой»;
  - если `scenarioIndex >= SCENARIOS.length`: текст про пройденную цепочку, `Select` сценария, «Играть сценарий»;
  - прогресс: `N / M`, id сценария.
- `disabled` при `inBattle` — как сейчас.

### 2.4. Вкладка «Персонаж»

- Заменяет кнопку «Профиль героя» и Modal **в хабе** — контент профиля **inline**.
- Содержимое:
  - сводка из бывшего `HeroProfileModal` (статы, бонусы экипировки, ожидаемый max ❤️ в следующем бою);
  - инвентарь (рюкзак);
  - селекты экипировки по слотам + Popover «Подробнее»;
  - список карт с подсказками по урону.
- Кнопку «Профиль героя» в хабе **удалить**.
- Экипировка/селекты **disabled** при `inBattle`.

### 2.5. Вкладка «Магазин»

- Текущий блок магазина: карточки товаров, цены, описания, «Купить».
- Логика `BUY_ITEM`, проверка золота, подпись про Memento — без изменений.
- Покупка **disabled** при `inBattle`.

## 3. Профиль героя в бою

- **`BattleScreen` и `HeroProfileModal` не меняются** по смыслу: в бою профиль по-прежнему открывается Modal.
- Рефакторинг: тело профиля вынести в общий **`HeroProfileContent`**, чтобы хаб и Modal не дублировали разметку.

## 4. Архитектура компонентов

| Файл | Ответственность |
|------|-----------------|
| `CampaignHub.tsx` | HUD + nav + `activeTab`, передача `campaign` / callbacks |
| `CampaignHubHud.tsx` | полоска статов |
| `CampaignHubNav.tsx` | три кнопки, `role="tablist"` / `role="tab"` |
| `CampaignBattleTab.tsx` | бой / реплей / прогресс |
| `CampaignCharacterTab.tsx` | `HeroProfileContent` + инвентарь + экипировка + карты |
| `CampaignShopTab.tsx` | магазин |
| `HeroProfileContent.tsx` | общий контент профиля (`mode`, `campaign`, `battle`) |
| `HeroProfileModal.tsx` | `Modal` + `HeroProfileContent` |

Колокация новых файлов вкладок: `src/features/campaign/`.

### 4.1. Состояние

- `activeTab: 'battle' | 'character' | 'shop'` — `useState` в `CampaignHub`.
- `profileOpen` в хабе — удалить.

## 5. Доступность

- Группа вкладок: `role="tablist"`; кнопки `role="tab"`, `aria-selected`; панель `role="tabpanel"`.
- `aria-label` на вкладках: «Персонаж», «Бой», «Магазин».
- Без агрессивного авто-focus при смене вкладки.

## 6. Вне объёма

- Роутинг URL на вкладки.
- Анимации переходов между вкладками.
- Сохранение `activeTab` в Zustand / localStorage.
- Изменения экрана боя, фаза 2 (инспектор врага).
